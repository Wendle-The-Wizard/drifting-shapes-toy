# Drifting Shapes Toy

A quiet little toy where soft glowing shapes drift across the screen and gently follow your pointer.

Right now (step 2 of 5) it draws soft, rounded circles, triangles and squares in pale colours on a dark night background. They sit still for now. Reload the page to scatter them somewhere new.

To try it, open the page in a browser, on a computer or a phone. Drifting and pointer-following come next!
